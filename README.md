# Portfolio — Lucía Lemes

Portfolio personal con temática espacial inmersiva. Single Page Application construida como un viaje continuo por el espacio profundo: navegación fluida entre secciones con transiciones de "viaje intergaláctico", animaciones de aterrizaje orbital y fondo estelar procedural.

## Stack previsto

- [Astro](https://astro.build/) — arquitectura de islas, HTML estático + hidratación selectiva
- [React](https://react.dev/) — islas interactivas (escena espacial, navegación, efectos)
- [Tailwind CSS](https://tailwindcss.com/) — estilos utility-first con paleta espacial custom
- Despliegue: Vercel
